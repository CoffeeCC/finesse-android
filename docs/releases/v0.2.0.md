### Android Auto (Music)
- Fixed tapping a song in an album or playlist sending `startIndex = -1` (`C.INDEX_UNSET`) to Jellyfin, which caused playback to fail silently.
- Made Android Auto browsing, search, voice play, and playback resumption resilient to dropped mobile connections (returns clean errors instead of crashing the session).
- Guarded audio stream URL signing (`ApiKey`) and artwork loading (`ImageProvider`) when signed out or reconnecting; bounded active URI permission grants so large libraries never hit Android 12+'s grant cap.
- Tapping the Now Playing notification now opens Finesse; fixed `PlaybackReporter` coroutine leak and stale stop positions on manual track skips.

### Phone WebView & Setup
- Stopped kicking users back to Server Setup if `finesse.session` isn't written to `localStorage` yet when capabilities fire.
- Moved all WebView connection callbacks onto the UI thread (fired once per load), cleaned up WebView callbacks/file-chooser handles on teardown, and stripped pasted `/finesse/...` subpaths & query strings during server setup.

### Finesse Video (Android Auto, parked only)
- Merged parked-safety rules (`ParkedRules` + unit tests): reversing (negative speed), `NaN`, and unknown speed gaps can no longer count as parked; uses monotonic `elapsedRealtime()`.
- Video transcoding waits until the car is actually parked (saves mobile data while driving), pressing Play retries after a network error, `+30s` seek clamps to duration, and Continue Watching loads in parallel and refreshes automatically when exiting the player.
